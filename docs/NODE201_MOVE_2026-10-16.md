## Design of the move

1. A **new** InfluxDB (`aggr-parallax-influx-201`) and a **new** server
   (`aggr-server-parallax-201`, fresh journal) start on node 201 before a UTC
   midnight, **T0**, beside the node-200 pair. No SQLite file is copied.
2. The new server writes to its own InfluxDB through `INFLUX_HOST`, not
   `hostAliases` (the prompt's first idea). That needs no ClusterIP pinned in a
   manifest.
3. A fresh instance makes no REST recovery burst at start
   (`recoverSinceLastTrade`, `src/exchange.js:532`, needs a last-trade time).
   While both run, two sets of venue WebSocket connections come from the same
   public IP.
4. After at least T0 + 4 h: compare `trades_1m` for [T0, T0+3h) per market;
   stop the node-200 server; take a final backup from node 200; restore it on
   201 as `aggr_parallax_hist`; run `scripts/backfill-history.js --execute`;
   switch Service `aggr-parallax-influx` to `app: aggr-parallax-influx-201`;
   re-pin the open-interest CronJob to **201** (it uses a local image, so it
   cannot simply be unpinned); scale node 200's InfluxDB to 0 and archive its
   journal cold.

If node 200 dies before the switch, the 12:59 backup plus node 200's on-disk
data (kept, `Retain`) cover everything before 12:59; bars between that backup
and the node-200 failure would have to come from a later backup or from
node 200's disk once it runs again.

## Open: journal write rate

Measured on node 200, 12:56–12:57 UTC, ZFS objset `nwritten` over 60 s: the
journal dataset takes **9.12 MB/s** of application writes (the InfluxDB
0.03 MB/s), 13.0 MB/s on the pool. `journal.js` runs SQLite in WAL mode with
`synchronous = FULL` and three indexes on `events`, so every trade is an
indexed insert and a later checkpoint. On 201's mirror (FireCuda 520 68 % and
Sabrent Rocket 4.0 74 % used, both with less endurance left than node 200's
SN200) that is about 1.1 TB a day per drive. Where the journal goes on 201 is
an owner decision recorded in the controller record (plan change 5); the
manifest puts it on the pool as the plan says.
